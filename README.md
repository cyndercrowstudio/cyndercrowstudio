# Hi, I'm Cynder! 👋

I'm 41, a resin, crochet, and bakery artist. I'm a gay mom — my son Drayven is 14 — and I have a girlfriend and a whole zoo of pets (pigeons, a rabbit, a dog, a kitten... it never ends lol).

I have ADHD and I'm a little autistic, and I'm using this page to try new things out in the open. Learning new things has started to feel scary — nobody wants to fail. But failing IS learning. That's how you learn anything in the first place.

So I'm going to show my failures here. The messy first tries, the things I mess up ten times before they work, the new stuff I dive into with nothing but a Wikipedia page and stubbornness. If that makes it a little less scary for someone else to try something new too, that's the whole point.

Come try new things with me. Let's learn together. 💜
